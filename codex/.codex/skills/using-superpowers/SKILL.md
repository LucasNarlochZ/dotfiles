# Using Superpowers (Opt-In)

Activate this workflow only when the user explicitly asks to use Superpowers, such as by saying “use your superpowers” or invoking `/superpowers`. Do not activate it merely because a task could benefit from a workflow or skill. For all other requests, follow the normal OpenCode instructions and use skills only when their own scoped descriptions apply.

When opted in:

1. Identify the task type and scope.
2. Load only the relevant Superpowers skills before acting. For new features or behavior changes, use brainstorming first; for bugs, use systematic debugging; when implementing code, use test-driven development if appropriate; use executing-plans only when there is a written plan to execute.
3. Follow the selected skills’ instructions, but scale the workflow to the task and respect the user's requested scope.
4. Do not force unrelated skills or steps into the task. Ask before expanding the request into substantial additional work.
